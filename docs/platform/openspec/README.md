# Planning artifacts

This directory is the cross-phase planning panorama referenced by `D:\code\docs\README.md`. It is intentionally separate from the active OpenSpec store at `D:\code\openspec`.

The change under `changes/add-sre-intelligence-evaluation-closed-loop` spans Phase 1B through Phase 4. It is a source backlog and requirement catalog, not one atomic implementation change and not evidence that unchecked tasks are implemented.

Before coding:

1. Select one phase and one bounded delivery outcome.
2. Create or update a scoped change in the active OpenSpec store.
3. Copy only the applicable requirements and tasks while preserving their service boundaries and safety constraints.
4. Apply and verify that scoped change.
5. Update a phase status only when every exit criterion has objective repository evidence.

The first eligible implementation scope is Phase 1B characterization, cross-service contracts, transport parity, and controlled ownership migration. Phase 2–4 work must not bypass its prerequisites.
